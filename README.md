Panel-split cover art maker in the GTA poster style: load any photo, slice it across 3-5 panels with per-panel crop and zoom, bold caption lettering, Vice City sunset or neon grade, and export a PNG at 1080x1080, 1080x1350 or 1920x1080. Static files, fully offline, photos never leave the machine.

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080
```

Build the hand-in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
